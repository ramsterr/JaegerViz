Capabilities

Everything you need to understand service topology.

Built for SRE teams that need to answer “what talks to what?” in seconds, not hours.

Directed dependency graph

Automatically builds a weighted directed call graph from Jaeger traces. Every edge carries call count and full latency distribution — average, P50, P95, P99.

Anomaly detection

Per-service P95 baseline with 2× threshold. Services exceeding the line are flagged as degraded or critical — clearly visible at a glance.

Interactive visualisation

Click any node to inspect metrics in a slide-out panel. Click any edge to see the latency distribution. Drag nodes, scroll to zoom, hit Ctrl+F to search.

Per-edge lag windows

P99 span duration × 10 safety multiplier, clamped between 1 and 30 minutes. Synchronous RPCs resolve to 1-minute windows. Asynchronous queue edges produce 20+ minute windows. Direct input for cross-correlation causal analysis.

Multiple export formats

Export the graph as JSON in node-link format, as DOT for graphviz, or as static images in PNG and SVG. Drop the output directly into downstream tools or dashboards.

Neighbourhood zoom

Filter the graph with --service cartservice --hops 2 to show only the services within N steps of your target. Indispensable when you have a hundred microservices.

Quick Start

Thirty seconds to your first topology map.

No Docker. No Kubernetes. Just Python 3.9+.

  • Clone and install

    git clone https://github.com/ramsterr/JaegerViz.git
    pip install -e .

  • Run the demo

    bash demo.sh

  • Browser opens with your interactive topology map
# Install the tool pip install -e . # Generate 300 sample traces (11 services, injected anomalies) python3 generate_sample_traces.py # Build and view topology-map render --from-file sample_traces.json --highlight-anomalies open topology.html
# Point at your Jaeger instance topology-map render \ --jaeger-url http://localhost:16686 \ --lookback 1h \ --highlight-anomalies # Export for downstream analysis topology-map export --format json --output graph.json topology-map lag-windows --output lag_windows.json
